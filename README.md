# CONTROLESAJ

Repositório destinado ao código-fonte do **Controle de Ordens de Serviço — Bahia Pneus, loja Santo Antônio de Jesus (SAJ)**.

## Site atual

https://bahia-pneus-os.gabrielmmoreira.chatgpt.site

> **Status da migração:** pendente de acesso aos arquivos-fonte originais. O site acima é uma implantação independente no ChatGPT Sites. Este repositório ainda **não contém o código do site publicado**, não está vinculado à implantação e não contém cópia dos dados operacionais.

## Escopo do sistema

- Operação exclusiva da loja SAJ.
- Ordens de serviço com numeração automática.
- Lançamento de diversos pneus, peças e serviços por OS.
- Vendedores e mecânicos cadastrados em categorias separadas.
- Edição de ordens abertas e ação explícita de conclusão.
- Registro de pagamentos divididos e acompanhamento financeiro.
- Interface simples para a equipe da loja.

## Como concluir a migração

1. Obter os arquivos originais do projeto hospedado no ChatGPT Sites (e eventuais migrações de banco, sem credenciais).
2. Importar o código-fonte para este repositório, preservando o histórico possível.
3. Configurar infraestrutura de execução e variáveis de ambiente por meios seguros.
4. Validar que as telas, regras, persistência e dados reproduzem o site original antes de qualquer troca de implantação.

**Atenção:** o link público do site não é um backup do código nem do banco. Não comitar tokens, chaves privadas, documentos de clientes ou dados financeiros reais neste repositório público.
